==================================================
四十、Existing Landscape Findings 必须纳入正式功能
==================================================

当前已经完成过一次 Broad Screening landscape analysis，
得到了一批有价值的 empirical findings。

这些结果不是 ground truth，
也不能硬编码进代码。

但新版 Broad Screening v0.1 必须能够从冻结输入
自动重新计算、复现和审计这些现象。

当前历史结果包括：

1. Top 4 pattern groups
   覆盖约 61.5% candidates；

2. PCA：
   PC1–3 cumulative variance ≈ 67.4%
   PC1–4 cumulative variance ≈ 72.4%；

3. 单独按 pattern 计算，
   覆盖 70% candidates
   仍需要约 66 patterns；

4. M01–M04 是主要 response groups；

5. M01 与 M02
   存在 gene overlap，
   但 module activity correlation ≈ -0.49；

6. 存在 gene-disjoint patterns
   response correlation ≈ 0.95；

7. M03 / M04 bootstrap stability ≈ 1.00，
   M02 ≈ 0.89，
   M01 ≈ 0.75；

8. candidate burden
   与 target cell count
   Spearman rho ≈ 0.333。

所有数字必须重新从冻结数据计算。

禁止：

assert(value == 0.615)

或：

hardcode M01 membership。

如果重新实现后数字变化，
报告差异并定位原因。
