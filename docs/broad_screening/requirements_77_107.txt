==================================================
七十七、Broad Screening v0.1 的核心验收问题
==================================================

Broad Screening 不能以：

“代码成功运行”

作为主要验收。

必须回答下面五个问题：

Q1.
6,129 candidates 是否表现出
shared response structure？

Q2.
这种 shared structure 是否在
reasonable analysis choices 下稳定？

Q3.
signed joint-state identity
是否包含 gene membership 之外的信息？

Q4.
是否存在 gene-disjoint
但高度 co-responsive 的 states？

Q5.
能否将 landscape 转化成
结构化、非冗余的 Deep Investigation case pool？

只有这五项都有明确输出，
Broad Screening v0.1 才算完成。

==================================================
七十八、Q1：Shared Response Structure 验收
==================================================

至少需要三类互补证据：

A. Candidate concentration

top-k modules candidate coverage

B. Low-dimensionality

PCA cumulative variance

C. Pattern diversity

达到 50/70/80/90%
candidate coverage
分别需要多少 individual patterns。

这三项必须一起解释。

不能只用：

Top4 modules = 61.5%

就声称：

“four modules dominate all responses”。

==================================================
七十九、Q2：Structure Stability 验收
==================================================

至少比较：

Pearson similarity

Spearman similarity

continuous signed delta representation

candidate binary representation

reasonable clustering cuts

target bootstrap

如果 major structure
只在一种特定设置下存在：

标记：

parameter_sensitive

不要称：

robust landscape structure。

==================================================
八十、Module Matching Across Sensitivity Runs
==================================================

不同 sensitivity run
可能产生不同 module numbering。

例如：

run A 的 M01

可能对应：

run B 的 M03。

因此实现：

module_alignment

基于：

pattern membership overlap

response centroid similarity

进行 matching。

不要根据 module ID 字符串
直接比较。

==================================================
八十一、Module Robustness Table
==================================================

输出：

module_robustness.csv

至少：

reference_module

alternative_run

matched_module

membership_jaccard

centroid_correlation

core_recovery

representative_pattern_recovered

direction_consistency

用于判断：

M01–M04
是否依赖某一个 clustering setting。

==================================================
八十二、Q3：Signed-State Information 验收
==================================================

这是 JURE Broad Screening
非常重要的 methodological question。

比较：

Representation A:
exact signed state

例如：

A+ B- C+

Representation B:
gene identity only

例如：

{A,B,C}

不能简单把不同 states
任意平均后比较。

必须定义清楚：

gene-only collapse rule。

==================================================
八十三、Gene-only Collapse Rule
==================================================

对于同一 gene triplet
存在多个 states 时，

gene-only representation
至少支持一种预先定义的 collapse：

例如：

对各 signed states 的
target-wise effects
做：

maximum absolute effect

或：

norm

或：

state-agnostic candidate indicator。

第一版优先使用：

state-agnostic candidate profile

作为直观 ablation。

必须明确：

collapse 后信息损失是人为定义的，
不是新的 biological statistic。

==================================================
八十四、Signed-State Ablation 指标
==================================================

比较：

signed-state representation

vs

gene-only representation

在以下方面：

module stability

within-module coherence

response correlation preservation

case redundancy

module separability

target clustering consistency

如果 signed state 有优势：

可以支持：

“Exact joint-state identity retains perturbation-response
information beyond gene membership.”

不能支持：

“Signed states reveal causal regulation.”

==================================================
八十五、Q4：Gene-disjoint Co-response 验收
==================================================

不能只展示：

一个 r=0.95 的漂亮 pair。

必须同时报告：

所有 gene-disjoint pattern pairs
的 correlation distribution。

例如：

median

95th percentile

99th percentile

maximum

以及：

top pairs。

这样可以判断：

r=0.95

到底是：

非常特殊

还是：

整个 landscape 普遍存在。

==================================================
八十六、Gene-overlap vs Response-correlation
==================================================

将 pattern pairs
按 gene overlap 分层：

0 shared genes

1 shared gene

2 shared genes

3 shared genes / same triplet different state

比较：

response correlation distribution。

目标：

回答：

response similarity
有多少可以由 gene overlap 解释。

输出：

gene_overlap_response_similarity.csv

==================================================
八十七、这个分析可能产生一个重要论文结果
==================================================

如果发现：

gene overlap = 0

仍存在大量高 response correlation pairs，

可以支持：

“Shared perturbation responses extend beyond
direct gene-set overlap.”

如果：

correlation 几乎完全随 gene overlap 增加，

也必须如实报告。

不要预设结论。

==================================================
八十八、Q5：Case Pool Compression
==================================================

Broad Screening 最后必须量化：

6,129 candidates

经过 landscape organization 后，

有多少属于：

redundant module-associated cases

module representatives

module-specific cases

cross-module cases

signed-state contrast cases

gene-disjoint co-response cases。

目标不是强行：

6129 → 20。

而是说明：

为什么后续 Deep Investigation
可以用一个结构化采样策略
覆盖 landscape 的主要类型。

==================================================
八十九、Case Selection Coverage
==================================================

未来如果选择：

Broad Screening 应能计算：

这些 cases 覆盖：

多少 modules

多少 landscape strata。

输出函数：

evaluate_case_set_coverage(case_ids)

后续人工选择 case 后
