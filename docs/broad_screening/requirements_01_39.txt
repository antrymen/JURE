==================================================
二、Broad Screening 的定位
==================================================

Broad Screening 不是：

1. 新的 statistical significance test；
2. 重新搜索 higher-order patterns；
3. 修改 Clue Hunting thresholds；
4. 给 6,129 candidates 再做一次 p-value 筛选；
5. 让 LLM 给每条 candidate 写机制解释；
6. 自动给 module 命名；
7. Deep Investigation；
8. Day 8 validation。

Broad Screening 回答的是：

“What global structure exists across the perturbation-associated
higher-order response landscape?”

核心关注：

1. 哪些 reference states 在很多 perturbations 下共同变化？
2. 哪些 perturbations 具有相似的 signed-state response profiles？
3. 是否存在稳定的 shared response modules？
4. module 内是否存在 stable core 与 unstable boundary？
5. 相同 genes 的不同 +/- states 是否表现不同？
6. 完全不重叠 genes 的 patterns 是否也可能具有同步 response？
7. 哪些 cases 适合进入后续 Deep Investigation？

==================================================
十二、为什么 gene-disjoint pairs 很重要
==================================================

Broad Screening 不应把：

简单解释成：

它可能来自：

或其他共同因素。

因此输出只称：

co-responsive patterns

或：

不要自动称：
