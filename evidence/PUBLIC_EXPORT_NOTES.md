# Public derivative archive

This archive preserves the 18 case identities and 11 recorded feedback chains. Nine third-party `evidence_excerpt` fields in six cases were omitted from the public export because their redistribution basis was not fully established. No numerical result, hypothesis, review, source URL or other JSON value was changed by this filtering step.

See PUBLIC_EXPORT_TRANSFORMS.json for each file, JSON pointer, parent hash and public hash. source_manifest.json preserves original source hashes and records the extra transformation. inventory.json verifies the present public bytes. Embedded historical hashes still refer to their original historical targets; do not compare them directly to filtered files as if the latter were unmodified originals. Complete parent records are retained privately, outside the release candidate.

## MED30 historical error

The historical output is preserved with this correction notice. It is not verified glioma evidence. See ../THIRD_PARTY_NOTICES.md for the source and version. This warning applies to inspection and interpretation of the MED30 case; it does not silently revise its historical review or outcomes.
